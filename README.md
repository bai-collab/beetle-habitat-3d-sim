# beetle-habitat-3d-sim

獨角仙智慧飼育箱的互動式 3D 網頁模擬專案。

## 設計基準
- 箱體外尺寸：200 × 200 × 300 mm
- 材料：3 mm 透明壓克力
- 感測器：箱內保護盒
- micro:bit 與電池：箱外固定
- 右後角：電線保護槽
- 後板上緣：U 型出線缺口
- 左右上方：通風孔

## 頁面
- `index.html`：Three.js 真正可旋轉 3D 模擬，可調整爆炸距離、感測器高度、飼養土高度與上蓋狀態。
- `exploded-diagram.html`：SVG 爆炸組裝圖，標示主要壓克力零件與電子模組位置。

## 操作
在 `index.html`：
- 左鍵拖曳：旋轉
- 滾輪：縮放
- 右鍵拖曳：平移
- 「爆炸距離」滑桿：分解/組裝箱體

Three.js 由 CDN 載入，因此頁面使用時需要網路連線。
